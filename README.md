# Healthcare Data Analysis and Insights

This project focuses on healthcare data cleaning, transformation, exploration, visualization, and dashboard creation using Microsoft Excel.

## Project Objective

The objective of this project is to analyze healthcare data from customer profiles, medical examinations, and hospitalization details to identify useful insights related to patient health conditions, hospital charges, and healthcare cost patterns.

## Files Included

- `Healthcare Data Analysis and Insights.xlsx`  
  Final Excel workbook containing cleaned data, transformed data, pivot tables, charts, slicers, and dashboard.

- `Healthcare_Data_Cleaning_Report 1.docx`  
  Report explaining the data cleaning process.

- `Healthcare_Data_Transformation_Report 2.docx`  
  Report explaining the data transformation steps.

- `Healthcare_Data_Exploration_Analysis_Visualization_Report 3.docx`  
  Report explaining the analysis, visualization, dashboard creation, formulas, and insights.

## Key Tasks Completed

- Checked missing values marked with `?`
- Filled missing month, year, smoker, hospital tier, city tier, and state ID values
- Split customer names into Title, First Name, and Last Name
- Converted number of major surgeries into numeric format
- Created Weight Status and Diabetes Status columns
- Created Date of Birth and Age columns
- Combined all tables into a Healthcare sheet using Customer ID
- Created pivot tables and charts
- Built an interactive dashboard with slicers

## Dashboard Insights

- Obesity with diabetes shows the highest average healthcare charges.
- Tier 1 hospitals generally have higher average charges than Tier 2 and Tier 3 hospitals.
- HbA1C increases with age, while BMI remains mostly stable.
- Healthcare charges increase as age increases.
- Cancer history distribution is similar among smokers and non-smokers.
